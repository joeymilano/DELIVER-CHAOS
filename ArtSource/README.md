## 来源与修改

- 三张角色参考图：内置 imagegen 原创生成，提示词与获准版本存于 References/Approved。无第三方品牌图样。
- 三只猫的 3D 生成：用户已登录的 Hyper3D 商业会员账户。正式交付前仍须保存对应账户的适用许可记录；“商业会员”截图不是完整许可凭证。
- 三只静态源模型各约 50 万三角面，静态展示版各 30,000 三角面（geometry-report.json）。骨架版保留 UV 和权重，经同一减面流程处理；动作信息见 rig-report.json。材质来自平台原生 PBR 2K。
- 本地材质修正：统一道具配色与粗糙度；猫增加少量原贴图色彩补偿，改善背光时黑猫眼睛的可读性。Tools/polish_materials.py 可复现。
- 动作为平台 Quadruped 的 CanineIdle/Run/Walk。不是专门制作的猫动画。移除了造成尾巴折叠的 Tail 动作轨，仍须实机检查四足接地、循环、转向和攻击衔接。
- 客厅道具与弹簧/音箱配件由本项目 Blender 脚本原创建模，不消耗 Hyper3D Credits。源脚本：Tools/build_room_art.py。导出：ArtSource/Environment；游戏资产：Content/Art/Props。
- UI 卡片使用已确认的设计参考；实机使用独立导入的骨架模型。两者分别验收。
