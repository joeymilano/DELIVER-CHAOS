# Party audio

OwnerCaught / OwnerGood / OwnerHome / Meow are temporary Mandarin synthetic voices rendered offline with eSpeak NG 1.52.0. Dialogue is original project text. The speech engine is not bundled. These are deliberately replaceable placeholders; they are not professional voice acting or a natural cat recording.

Clink / Thud / CameraOff are original short synthesized game effects produced by Tools/prepare_party_audio.py. No background music is generated or included.

Run the script with espeak-ng installed, then Tools/import_party_assets.py in Unreal Editor to rebuild.
