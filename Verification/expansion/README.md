# 扩房与 Fab 接入验证

日期：2026-10-31。引擎 UE 5.8.4，macOS Apple M5 Max。

## 已验证

- 三套 Fab 资源已下载、导入；56 个家具／装饰静态网格，两个角色使用同一资源包的骨骼模型。
- Mac 原生包编译、烘焙和归档成功；关闭编辑器后独立启动。
- 高清根因：应用 Info.plist 的 NSHighResolutionCapable=false。修为 true 并重新本地签名后，1920×1080 原生绘制正常，不再出现放大到 2880×2160 的模糊 4:3 画面。build_mac.sh 已包含修复步骤。
- 11 项自动检查通过，0 失败，包含 Fab 人物网格及四个动画的可加载性、房间边界和高猫道碰撞、180 秒计时和重开清理。
- 手动按键实测：从出生点移动至台阶，Space 跳跃配合前进可连续登上 2.8 米高猫道；HUD 隐藏、重试和不限时模式可用。
- 人物动作重新导入必须单独导入 AnimSequence；只重导骨骼网格会保留旧动画，工具已修正。

- 实机触发了主人抓包，出现“被逮到了！快上高处。”并把猫赶开；恢复移动正常。近距离人物挤压镜头的问题已改为人物忽略相机碰撞。
