# OIIA 结算彩蛋

一局结束，猫在小台上绷着脸转三阵，再把账单交给你。表演约 4.8 秒，使用本局出场的猫模型和合成配件。

- 有损失时显示“本场拆家 MVP”，零损失时显示“本场摸鱼 MVP”。
- Space 或“好了，看账单”立即结束表演；账单页 Space 或“再转一圈”重播。
- R 重试、返回选猫会清空舞台和音频；暂停同时停止动画和音频。
- 表演不增加金额，不重复记入排行榜。不转镜头，不影响游戏角色的碰撞。

## 制作

`LabMeme.cpp` 定义三段完整旋转及正面停顿；固定机位、无碰撞台座和独立补光只在结算时创建。四猫共用同一段动作，无需新的绑定或生成服务。

参考是用户提供的 `c7eeb0fc899321cb4ceaf52e4060e31c.mp4`。原文件未修改。前 4.8 秒音频转为单声道 WAV、末尾淡出，用于本机演示；此来源没有提供再分发许可记录，源 WAV 和对应 Unreal 音频资产已排除出公开 Git。

公开源码在无音频时仍可正常播放转圈动画。需要导入已获授权的替换音频时，放入 `ArtSource/Audio/LocalReference/OiiaReference.wav`，运行编辑器脚本 `Tools/import_meme_audio.py`。当前本地演示包含参考音频，后续公开发布包前需替换为允许再分发的音频或移除该资产重新打包。

## 验证

自动测试覆盖旋转停顿、禁止游戏阶段触发、金额保持、跳过、连续十次重播、自然结束、选猫及重试时清理舞台。

开发版画面检查可使用 `-NoSave -UIReview=mvp`；加 `-MemeReview` 仅供连续观察，正常游戏不会循环播放。该检查使用测试账单，不能作为真实玩家成绩。
