# 猫叫结算与猫猫彩蛋

高速旋转已经移除。结算采用当前猫的骨骼模型，轻微抬头、张嘴，播放一声已有 CC0 猫叫；约 2.2 秒后回到账单，Space 可立即跳过。没有 OIIA 配乐，也不再接主人回家对白。

账单页按 Space 或点“猫猫彩蛋”，展示用户提供 OIIA 视频提取的透明动图卡片。12 fps、32 帧，两遍后自动收起，可随时再次关闭。动图不替换玩家角色动画，也不改分数。

本地素材来自用户在对话中提供的 c7eeb0fc899321cb4ceaf52e4060e31c.mp4。截图帧和 GIF 在 ArtSource/MemesLocal，Unreal 图集在 Content/UI/MemesLocal，均不上传公开仓库。公开源码在缺少素材时不展开彩蛋。原参考音频不再被结算加载。对外发行前仍需确认该梗素材的使用许可。

导入脚本 Tools/import_meme_gif.py。游戏使用透明帧图集播放，同步保留可直接预览的 oiia-easter-egg.gif。
