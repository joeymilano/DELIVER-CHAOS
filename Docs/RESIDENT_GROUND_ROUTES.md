# 人物地面移动修复

主人与客人改为沿客厅地面规划路径，绕过家具占地。猫在桌面或高处时，追踪目标落在最近可达的地面位置；人物不会跟随猫爬上家具。

## 实现

- 用固定房间的 40 cm 地面网格做 A* 路径。每个节点检查站立胶囊、地面支撑和家具完整占地，路径段同样检查。家具模型碰撞不完整时，仍禁止人物进入其占地。
- 转弯前减速，收紧路点到达范围，替换每帧碰撞法线左右转向。未能前进时停止并延时重规划，避免持续顶着障碍抖动。
- 人物胶囊忽略 PhysicsBody，关闭角色移动的物理推力、踩压和推动冲量；散落道具不会卡住人物，也不会被人物踢飞。猫与道具的原有互动保留。
- 人物只允许 3 cm 地面接缝步差，家具阶梯不属于人物路线。重置时选可站立的地面位置；异常高度回到最近安全地面。
- 删除宠物摄像头的可见锥体。视野、遮挡检测、嫌疑反馈和抓捕惩罚继续工作。

这套路径针对当前固定客厅。日后移动固定家具后，应重新调用 BuildGroundGrid；人物对散落物件使用忽略碰撞，不加入逐个踢开障碍的行为。
