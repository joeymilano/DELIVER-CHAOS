# 猫手猫脚：开始界面

启动进入独立首页：奶油白大字、橙色主按钮、实时渲染的猫与 Fab 家具场景。猫轻微转头、摆尾，没有高速旋转。

- 开始捣蛋 / Enter：选择猫后进入限时玩法。
- 随便拆拆 / F：选择猫后进入不限时玩法。
- 音乐开关 / M：当前会话全局 BGM 静音，不影响操作音效。
- 选猫 / 合成页按 Esc 返回首页。

音乐使用 PR #2 的 Pixabay Menu 音轨。开局切换 CanCan；追赶和最后 20 秒切换 Chase，结算轻声保留 CanCan。M 静音继续生效。授权记录保存在随包 Licenses，界面不显示制作或授权面板。

首页道具独立于玩法房间；进入选猫与开局时销毁，返回首页重建。自动测试覆盖入口、限时/不限时状态、重复返回无场景累积、R 不误开局。
