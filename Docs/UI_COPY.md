# 猫手猫脚界面与文案

这轮使用 Human Writing 改写游戏内短文案。每段文字只承担一件事。按钮说清下一步，能力说明告诉玩家怎么操作，猫的台词留给人物性格。台词可以嘴硬，数值和操作提示必须准确。

## 保留什么

首页只放游戏名、入口与音乐开关。选猫卡片保留名字、能力、状态和藏身线索。合成页保留搭档、结果与解锁条件，结算页保留金额、物件明细、成绩和榜单。去掉页面口号、卡片格言与重复副标题。

## 页面与下一步

选猫页以主角大图为中心。其他猫按两行排列，未发现的猫显示具体藏身线索。已有一只猫时，主按钮写“开始拆家”。找到第二只后，按钮改成“选搭档”。

合成页展示两只猫、组合名称和获得的能力。隐藏组合尚未解锁时，显示真实条件，主按钮禁用。玩家也可按 Space 单猫出门，或按 Tab 重选主猫。

游戏 HUD 保留账单、回家倒计时、监控状态和超级扑次数。Q 提示只向拥有喵声冲击的猫显示。新手提示、主人台词和发现猫的消息短暂出现，不长期挡住客厅。普通扑没有次数限制，超级扑耗尽后明确提示仍能继续扑。

结算页是一张实际账单。按物件名称汇总金额，优先显示最高的三项，其余合并列出，合计等于本轮损失。空账单显示“暂无损失”。右侧保留监控判定和本机榜单，不用连锁倍率占据主视觉。

暂停页集中放操作说明和震动开关。返回选猫、重新开始都提前说明会结束当前一局。

## 视觉实现

保留奶油白、炭黑、橙色和雾蓝。橙色用于主按钮、选中状态与账单金额；危险另用红色和文字共同表示。卡片、按钮、键帽统一圆角和间距。中文使用 Noto Sans CJK 简体中文常规与粗体，字体原文件及 SIL OFL 许可随游戏保留。中文字按实际字体高度测量，长标签按可用宽度收缩，说明文字自动折行。

界面以 1280 × 720 为安全区域，保持比例居中。背景覆盖整个窗口，内容不随超宽窗口横向拉伸。没有增加网络依赖或生成服务开销。

## 开发检查入口

Development 包支持 `-NoSave -UIReview=locked|collection|lab|hidden|fusion|hud|pause|results|empty`。每次传一个状态。测试入口只在显式启用 NoSave 时生效，不在屏幕显示测试标注，不改玩家存档。结果预览用实际道具计价生成账单。

真实游戏从普通启动进入，测试预览不能算作玩家完成了收集或合成。
