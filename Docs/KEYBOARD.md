# 纯键盘操作

现场使用键盘即可完成开始、选猫、合成、拆家、暂停和重试。

| 按键 | 操作 |
|---|---|
| 方向键或 WASD | 按屏幕方向移动 |
| J | 挥爪，自动选择附近目标 |
| 长按 J 后松开 | 蓄力扑击 |
| Space | 跳跃 |
| 按住 E | 慢推附近目标 |
| 方向键、Enter | 菜单选择、确认 |
| Esc | 暂停或返回上一级 |

Shift 暴冲、Q 音波、R 重开、Tab 选猫、C 镜头远近、H 隐藏界面、V 震动和 M 音乐仍作为可选快捷键。合成页 Space 可单猫出门；结算页 Space 可跳过喵叫或查看彩蛋。数字 1–4 仍可选猫。

## 镜头与选目标

镜头保持朝向并自动跟随，不读取鼠标转向。猫转身不会带着镜头转；靠近桌椅时，避障恢复沿同一朝向改变高度与距离。方向键按镜头的水平轴映射，不依赖旧的鼠标朝向。攻击方向跟随最近一次实际移动输入。

附近目标用橙色小箭头标出，底部显示物件价格、J 拍与 E 推。轻攻击与慢推使用相同的 170 cm 基础目标范围，并检查遮挡；扑击范围更长。目标选择保留宽松的朝向偏好，释放攻击或慢推时自动转向目标。

菜单有橙色键盘焦点。方向键在选猫网格中跳过未解锁的猫和已选主猫，Enter 确认；暂停与结算按钮同样支持方向键和 Enter。移除鼠标攻击和转视角映射，避免窗口激活时误出爪。
