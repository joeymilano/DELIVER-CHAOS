# 破坏金币反馈

每件物品首次计入拆家账单时，在物件上方爆出旋转金币和 `+¥金额`。贵重物件金额更大、金币更多；金币随后沿弧线飞向左上账单，账单滚动并轻弹。相邻金额互相避让，微小损失合并展示。

杯、瓶、碗、台灯等用已提供的 Glass 碎裂声，其余用 Landing。金币另用提供的收银机录音剪成 0.65 秒，冷却 0.14 秒，连续触发时淡出上一声，连锁越长音调略升。来源与处理记录见 `Content/Licenses/Pixabay.txt`。

## 边界

- 沿用物件一次性计费；重复碰撞不产生新钱。视觉反馈使用同一笔实际账单金额。
- 同屏最多 12 组、每组最多 8 枚金币，均为绘制效果，不增加碰撞刚体。
- 0.16 秒、250 cm 内的小额损失合并金额；效果 1.5 秒内清理。
- 重试、返回选猫、结算时清理效果和声音；隐藏 HUD 时隐藏金币反馈。
